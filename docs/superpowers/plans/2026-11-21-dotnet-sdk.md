# Zero C# .NET SDK Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `dotnet new zero` + `dotnet build` make a native zero-mode program on Linux, with editor support, library projects and packable zero libraries, from NuGet packages, without cloning this repository.

**Architecture:** An MSBuild project SDK (`ZeroCSharp.Sdk`) layered on `Microsoft.NET.Sdk`: it gives projects a target framework of their own (`zero0.1`), compiles against prebuilt zerocore and `lib/` with a pinned Roslyn 5.12.0, and for executables runs bflat from a per-host package (`ZeroCSharp.Bflat.<rid>`, a trimmed layout) on the project's sources. Templates come in `ZeroCSharp.Templates`.

**Tech Stack:** MSBuild/.NET 10 SDK, NuGet, bash, Docker (for tracing and clean-distro tests), GitHub Actions, the bflat fork (OnurGumus/bflat).

**Spec:** `docs/superpowers/specs/2026-11-21-dotnet-sdk-design.md`

## Global Constraints

- Hosts in v1: Linux x64 and Linux arm64, on Ubuntu 22.04 and 24.04, Debian 12 and Fedora, with no extra system packages. Windows host: 0.2. macOS: everything but the native step.
- Targets in v1: `linux-x64`, `linux-arm64`, `win-x64` (property `ZeroTarget`, default: the host's own).
- Compiler pinned: `Microsoft.Net.Compilers.Toolset` 5.12.0; `LangVersion=preview`, `Features=updated-memory-safety-rules`, `AllowUnsafeBlocks=true`.
- First version 0.1.0. Target framework `zero0.1` (major.minor of the SDK).
- Package ids: `ZeroCSharp.Sdk`, `ZeroCSharp.Bflat.linux-x64`, `ZeroCSharp.Bflat.linux-arm64`, `ZeroCSharp.Templates`. Templates: `dotnet new zero`, `dotnet new zerolib`.
- Licenses: SDK and templates MIT; bflat packages AGPL-3.0 with the fork's source URL and commit.
- No network during `dotnet build` beyond NuGet restore. Never ship the full layout.
- bflat flags: copy from `build.sh` (`build_core`, `build_lib`, `build_native`, `build_win`); `build.sh` is the reference.
- macOS native-step error text, exactly: `Zero C# can't make native programs on macOS yet; build on Linux or Windows, or use the repository's build.sh.`
- Version-mismatch error names both versions; packages built with another major.minor are refused.
- `build.sh`, `libs/` and `test.sh` keep working unchanged.

## Review Focus

- A project path with spaces: bflat arguments must be quoted (Task 6 test `path with spaces`).
- No change → no bflat run; a changed referenced library → bflat runs (Task 6 test `incremental`, Task 7 test `library change rebuilds`).
- bflat-only failures (e.g. a missing link input or a `[DllImport]` of an unknown library) surface as MSBuild errors, not a silent success (Task 6 test `bflat failure fails the build`).
- Sources in subfolders and `<Compile Remove>` honored: bflat gets exactly `@(Compile)` (Task 6 test `compile items`).
- A fresh NuGet extraction loses the executable bit; the first build on a clean machine must still run bflat (Task 6 test on clean containers, Task 9).

## File structure

```
sdk/
  version.props                     SDK version (0.1.0) and derived TFM (zero0.1), shared by all packs
  ZeroCSharp.Sdk/
    ZeroCSharp.Sdk.csproj           packs Sdk/, payload/; no code
    Sdk/Sdk.props                   TFM, framework off, compiler pin, references
    Sdk/Sdk.targets                 native step, library checks, macOS error
    payload/                        generated by build-payload.sh (git-ignored)
  ZeroCSharp.Bflat/ZeroCSharp.Bflat.csproj   packs a trimmed layout for one host RID
  ZeroCSharp.Templates/             template pack: content/zero, content/zerolib
  build-payload.sh                  zerocore/lib dlls + link objects -> ZeroCSharp.Sdk/payload
  trim-layout.sh                    trace + copy + strip a layout -> a trimmed layout
  pack.sh                           builds payload, trims, packs all four into sdk/feed/
  test/
    run.sh                          the SDK test suite (bash; one function per test, exit code = failures)
    fixtures/                       small projects used by run.sh
.github/workflows/sdk.yml           packs, tests on clean runners, publishes on tag sdk-v*
LICENSE                             MIT (root, new)
```

Fork (OnurGumus/bflat): `.github/workflows/lld.yml` (new), `src/bflat/bflat.csproj` (lld overlay).
